## About Me

I'm a Full Stack Developer with 4+ years of experience building and modernizing enterprise applications.

Currently, I work on the modernization of the Maxys® ERP at Maxicon Sistemas, migrating legacy Oracle Forms applications to scalable Angular + Spring Boot architectures, contributing to Micro Frontend strategies, reusable component libraries, REST APIs, and enterprise workflow optimization.

My background combines frontend engineering, backend development, UI/UX, Design Systems, and architecture-oriented thinking.

- Frontend: Angular, TypeScript, React, RxJS, NgRx, Micro Frontends
- Backend: Java, Spring Boot, REST APIs, Oracle, MySQL
- Architecture: Scalable systems, reusable libraries, clean code, modular applications
- DevOps: GitLab, Jenkins, Nexus, CI/CD pipelines
- UX: Design Thinking, Double Diamond, UI consistency, user-centered interfaces
- Certifications: AWS Cloud Foundations and Introduction to Cybersecurity
